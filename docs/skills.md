# 专项 skill 与问题案例

单文档检查同时提供现有检查项和专项 skill。现有检查项执行宽泛检查，专项 skill 使用明确的判定方法识别已确认的问题模式。常用词、敏感词和超链接检查继续使用各自的程序规则。

## 三步开始使用

1. 在“公共规则 → 专项 skill”粘贴原文，说明为什么有问题，点击“整理成专项草稿”。正确写法可选。
2. 核对页面带出的原文和问题说明，勾选人工确认，点击“确认并启用此专项”。名称、判断步骤和期望结果由工具按模板整理，可以在高级设置中调整。
3. 创建单文档检查任务，在“专项 skill（按需选择）”勾选这个专项，再提交文档。

例如，原文填“参数表写默认超时 30 秒，附录写默认超时 60 秒”；问题说明填“两处描述同一设备、同一版本、同一运行模式，默认值应当一致”。已经确认正确值时，正确写法填“产品负责人确认统一为 30 秒”。

草稿整理使用内置模板。保存时保持待确认状态；点击确认后，系统确认案例，有示例空位时加入正式检查，并按用户选择启用专项。已有的示例选择继续保留，真实问题和正确反例各最多两条。

拥有公共规则管理权限的用户可以操作上述入口。超级管理员也可以从系统设置进入。现有检查项默认勾选，专项由用户按文档场景选择。删除或取消确认最后一条已确认真实问题时，专项自动停用。

## 继续积累案例

打开已有专项，在“再记录一个问题或正确反例”填写原文和问题说明，保存后核对并确认使用此案例。工具保留现有判断规则；空白专项会根据第一条真实问题整理规则草稿。

模型误报可以录入为正确反例：展开“更多信息”，类型选择“正确反例”，在问题说明中解释为什么应当放行。人工发现的漏报作为真实问题录入。

报告条目的“固化为案例”进入专项页面，原文、位置、来源任务和可用的文档内容会自动带入。填写人工确认的问题理由后，可以创建专项或选用已有专项。

“更多信息”按需要补充案例名称、文档版本、原文位置、期望结果和验证上下文。未补充上下文时，系统使用已提供的原文片段验证，并在页面标明验证范围。缺失类问题提供完整文本，以便核对全文及相关引用。

## 高级设置

“高级设置：调整判断规则、名称与启停”包含检查目标、适用条件、判断步骤、必要证据、排除条件和修改建议原则。系统统一提供报告格式、原文定位、证据门槛和文档解析限制。可展开实际执行提示词核对执行内容。

“高级设置：选择代表性示例”用于调整正式检查引用的已确认案例。保存相同选择保持当前版本，各示例字段最多引用 400 字，完整验证文本供独立验证任务使用。

“案例库与验证”中的“编辑案例内容与证据”可以细化下列信息：

- 案例名称与类型：真实问题，或应当放行的正确反例。
- 文档、版本及适用场景：标明产品、型号、运行模式和相关条件。
- 证据位置与原文证据：保留原句和必要上下文；一致性问题提供两处原文。
- 确认理由与权威依据：解释问题为什么成立，或反例为什么正确；业务规范同时说明来源与适用范围。
- 期望检查结果：说明应报告的具体问题，或明确反例应当放行。
- 验证文本：粘贴完整验证上下文。信息缺失案例需要核对全文及相关引用内容。
- 确认后的修改内容：可选填写经过核实的正确表述。

## 验证与版本

需要确认检查效果时，展开“案例库与验证”，选择当前用户的可用模型，点击“执行案例验证”或“验证这段原文”。验证可以在确认启用前执行。系统以所提供的验证文本创建独立单文档任务，使用当前专项规则和其余代表性示例；被验证案例自身从提示词示例中排除。期望结果作为任务快照和报告复核资料保存，验证提示词使用检查规则与参考示例。验证任务展示完整检查结果，同一用户重复提交执行中的案例会复用当前任务。

验证成功完成后，打开报告对照期望结果，在案例页面保存“通过”或“未通过”及复核说明。真实问题需要识别期望的问题，正确反例需要正确放行；未通过时填写漏报、误报或结论偏差。系统保存任务、规则版本、复核人、复核时间和说明，页面汇总当前版本的通过、未通过和待复核数量。

规则、案例内容和代表性示例修改会更新版本。旧版本的复核显示为历史结果，当前版本需要重新验证和复核。重新执行验证、修改案例或删除验证任务后，该案例进入待验证或待复核状态。版本预览、案例验证和人工复核共同帮助确认适用边界。

普通任务提交时保存专项版本、完整规则、实际提示词和示例案例编号。后台执行与重试使用任务快照。案例及规则存储在 `instance/` 的 SQLite 数据库中。

系统设置提供“含专项 skill 的单任务报告条数上限”，`0` 表示展示全部条目，正整数在合并后限制整个任务的报告条数。任务提交时同时保存该设置，原始结果与人工反馈继续保留。

## 报告合并

有专项参与时，系统按相同原文证据、相同问题描述和相同判定类型合并跨检查项重复条目，汇总位置并展示共同发现的检查项及专项版本。证据或描述不同的条目分别保留。常用词、敏感词和超链接结果使用各自的报告处理。

已提交的人工反馈继续保留；存在相互冲突的人工反馈时，条目分别展示。原始模型回复始终保存，HTML 和 Excel 报告展示合并后的问题与来源。
