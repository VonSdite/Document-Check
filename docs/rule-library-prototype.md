# 检查规则库交互原型

原型以待审核工作台为入口，展示批量人工反馈自动收录、去重归类、规则归纳、自动验证、按主题审核和增量归档。人工操作集中于新规则与异常。页面使用内置示例数据，操作记录保存到当前浏览器的独立存储空间，支持导出 JSON 和重置。

## 打开方式

- 在工具的“检查规则”页面点击“检查规则库原型”。
- 直接用浏览器打开 `app/web/static/rule-library-prototype/index.html`。
- 服务运行时访问 `/static/rule-library-prototype/index.html`，部署有路径前缀时使用设置页入口。

原型静态资源仅包含虚构示例，可独立打开。真实报告、用户身份、数据库、模型配置及现有误报规则继续使用项目现有流程。

## 推荐体验顺序

1. 查看工作台：1,008 条反馈自动合并为 216 条去重案例，保留 215 份独立证据；形成 3 条待审核规则和 2 类待处理异常。
2. 点击“选择同范围规则”，一起选择 VX120 的电压与电流规则，打开批量审核摘要。核对判错条件、例外和代表性原文后，一次启用两条规则。
3. 点击“模拟收到一批反馈”，选择“同类问题为主”。新增 120 条反馈直接归入已审核主题，待审核规则数保持不变。
4. 再选择“包含新产品范围”。BX300 的反馈单独形成候选，等候范围审核。
5. 在“异常与冲突”核对同源相反反馈，保留待确认或记录有依据的裁定。认可核查价值的建议可保留为待核实案例归档。
6. 在“反馈归档”按主题筛选、搜索和分页，查看原始反馈、原文、合并数量及处理状态。
7. 在“文档试运行”切换六种情境，查看已审核例外的自动核对、证据不足提示及可选的人工抽样复核。
8. 调整规则条件，观察保存后的自动验证结果；发布新版本或停用规则后，在“运行与版本”查看历史快照。

待审核卡片展示正例、反例、独立证据数和自动验证结果。批量审核限定相同产品、文档类型、版本与检查项，独立来源较少的候选单独审核。旧误报参考 L-001 与相关例外关联，条件审核后由系统在检查时自动核对。

## 数据与判定范围

案例保存原文、人工反馈、文档上下文、来源、合并次数和主题关联。重复导入按反馈事件标识跳过；同源重复检查合并为案例，相反反馈分别保留。主题按检查内容、检查项、产品、文档类型和版本划分。检查规则保存范围、判错条件、证据要求、例外条件、案例来源、草稿及发布版本。

电压、电流和术语检查采用结构化的预设场景。主题归类使用示例元数据，规则草稿来自预设模板，自动验证回放已标注的示例事实与边界场景。产品、文档类型、版本、例外开关及发布状态影响模拟执行，自然语言条件作为审核说明展示。真实语义聚类、模型归纳和独立文档效果评估属于后续服务接入范围。

符合已审核判断边界的新反馈自动归档，保留规则版本和启停状态。新增范围、相反反馈、未确认建议或验证失败进入待办。人工裁定独立记录，只应用于当时明确处理的案例；后续新证据继续参与验证。机器判定与人工反馈分别记录，只有明确的人工反馈进入规则依据。

保存规则修改后自动验证，通过后进入审核，失败时展示具体案例。批量审核先验证所有选中规则的范围、状态和摘要版本，再统一发布；审核摘要打开后规则或独立样本变化时，重新查看摘要再发布。待审核修订与已发布版本独立保存。试运行冻结规则快照，后续编辑、停用和人工反馈均保留原始结果。

## 文件与验证

- `app/web/static/rule-library-prototype/index.html`：独立页面入口。
- `prototype.css`：桌面与移动端布局。
- `model.js`：规则生命周期和模拟判定。
- `automation.js`：批量示例反馈、去重归类、自动验证、批量审核和增量归档。
- `workbench.js`：待办工作台、主题详情、分页归档、浏览器存储与记录导出。
- `tests/test_rule_library_prototype.js`：发布门槛、例外与证据、版本快照和反馈边界验证。
- `tests/test_rule_library_automation.js`：批量处理、范围隔离、原子审核、增量归档和裁定边界验证。

```bash
node --test tests/test_rule_library_prototype.js tests/test_rule_library_automation.js
uv run ruff format .
uv run ruff check .
```
